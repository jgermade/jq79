# Keyed js-framework-benchmark implementations

Six implementations of the standard
[js-framework-benchmark](https://github.com/krausest/js-framework-benchmark)
row table — create/replace/update/select/swap/remove/clear at 1,000 and
10,000 rows — one per framework:

- [`jq79/`](jq79) — the reason this directory exists
- [`vanillajs/`](vanillajs) — hand-written DOM, no framework: the baseline
- [`preact/`](preact), [`vue/`](vue), [`svelte/`](svelte), [`react/`](react)

Each is a standalone Vite project (`npm install && npm run build`), laid out
to match the upstream benchmark repo's `frameworks/keyed/<name>/` convention.
Two things are shared rather than duplicated per framework:

- [`_shared/data.js`](_shared/data.js) — row generation (the adjective/colour/
  noun word lists, the id counter, the update/swap algorithms), so every
  framework builds identical rows from identical inputs.
- [`_shared/public/`](_shared/public) — the vendored Bootstrap 3.3.6 + glyphicon
  assets the upstream benchmark's pages use, referenced via each app's
  `publicDir` in `vite.config.js`.

All six use the same element ids and DOM structure (`#run`, `#runlots`,
`#add`, `#update`, `#clear`, `#swaprows`, `#tbody > tr > td`), which is what
lets one benchmark runner drive all of them identically.

## Results

- `/benchmark/` — jq79's own numbers in isolation, tracked release over
  release.
- `/benchmark/comparison/` — all six, measured the same way in the same run,
  generated by [`scripts/run-comparison.mjs`](../../scripts/run-comparison.mjs)
  (`npm run benchmark:comparison` from the repo root).

Neither is the official `webdriver-ts` harness — see the methodology note on
each results page for what that means for the numbers.
