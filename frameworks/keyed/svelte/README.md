# Svelte (keyed) — js-framework-benchmark implementation

Svelte 5, runes (`$state`), via `@sveltejs/vite-plugin-svelte`. See
[`frameworks/keyed/README.md`](../README.md) for how this fits alongside the
other implementations.

```sh
npm install
npm run dev     # vite dev server
npm run build   # → dist/
```
